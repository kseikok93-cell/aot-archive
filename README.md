# موسوعة وأرشيف هجوم العمالقة الشامل (Attack on Titan Encyclopedia & Archive)

موسوعة تفاعلية ضخمة باللغة العربية (RTL) بتصميم داكن احترافي مستوحى من عالم "هجوم العمالقة"، تغطي المانجا الأساسية وجميع الأعمال الجانبية الرسمية (Before the Fall، No Regrets، Lost Girls).

---

## 🚀 طريقة تشغيل الموقع في المتصفح

### الطريقة الأولى (الأسهل بنقرة واحدة - مستحسن):
1. افتح المجلد: `C:\Users\gg\.gemini\antigravity\scratch\aot-archive`
2. اضغط مرتين (Double-click) على الملف:
   ```
   run_archive.bat
   ```
   سيقوم بتشغيل خادم بايثون المحلي وفتح المتصفح تلقائياً على الرابط: `http://localhost:8000`.

### الطريقة الثانية (عبر موجه الأوامر PowerShell أو CMD):
افتح موجه الأوامر في مجلد المشروع ونفذ:
```powershell
cd C:\Users\gg\.gemini\antigravity\scratch\aot-archive
python -m http.server 8000
```
ثم افتح متصفحك (Chrome، Edge، أو Firefox) على:
[http://localhost:8000](http://localhost:8000)

## 📂 هيكل المشروع وقاعدة البيانات

```
aot-archive/
│
├── index.html                  # واجهة التطبيق الرئيسية (RTL + Dark Mode)
├── style.css                   # ملف الأنماط والتصميم الداكن والتأثيرات
├── app.js                      # محرك التطبيق، جلب البيانات، الفلاتر والملف الكامل
├── run_archive.bat             # ملف تشغيل سريع للموقع بنقرة واحدة
│
└── data/                       # قاعدة البيانات المقسمة لسهولة الإدارة
    ├── timeline.json           # التسلسل الزمني للأحداث (يمير فريتز -> دك الأرض)
    ├── chars_main.json         # الشخصيات الرئيسية والمحورية
    ├── chars_scouts_military.json # فيلق الاستطلاع، الحامية، والمدربون
    ├── chars_marley_world.json # محاربو مارلي، عائلة تايبر، والمتطوعون
    ├── chars_spinoffs.json     # شخصيات الأعمال الجانبية (Before the Fall، No Regrets...)
    └── titans_lore.json        # العمالقة التسعة، أشجار التوارث، والتكنولوجيا العسكرية
```

## ✍️ كيفية إضافة دفعات جديدة من الشخصيات والأحداث

جميع البيانات محكومة بنماذج واضحة في ملفات JSON داخل مجلد `data/`:

1. **لإضافة شخصية جديدة:**
   - افتح الملف المناسب في مجلد `data/` (مثلاً `chars_main.json` أو `chars_spinoffs.json`).
   - أضف كائناً جديداً باتباع نفس الحقول المرجعية (الاسم، الألقاب، الإحصائيات، القصة، العلاقات، والأسرار).
   - احفظ الملف وقم بتحديث صفحة المتصفح (`Ctrl + F5`) وستظهر الشخصية فوراً في البحث والفلاتر!

2. **لإضافة حدث تاريخي جديد:**
   - افتح `data/timeline.json` وأضف الحدث متضمناً `year` و `year_sort` لترتيبه تلقائياً.
